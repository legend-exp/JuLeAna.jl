Muon-veto PMTs

PMT calibration

JuLeAna.process_pmts_calibration_cal — Function
process_pmts_calibration_cal(processing_config, l200::LegendData, period::DataPeriod, run::DataRun;
    reprocess::Bool=false, timeout::Real=0)

Calibrate the muon-veto PMTs (pmts) of one run from the LED calibration (MVC) data.

A run has one MVC file; files listed in datasets/ignored_daq_cycles of the metadata are left out. A run without MVC files is skipped; then no validity entry is written and the calibration of the last LED run stays valid. A run with more than one MVC file fails: the files that are not used have to be listed there or removed first.

For each PMT selected by detectors in the processing config and each energy type of the calibration configuration, the raw waveforms of the file are processed with dsp_pmts, the qc cut is applied, and the single-photoelectron (1 p.e.) peak is fitted with LegendSpecFits.fit_pmt_spe. A fit that did not converge or fails one of the quality cuts gets the status warning, with the failed cuts in the report, and is stored with a NaN calibration, so the PMT drops out of the muon cut of this run. With the report_status of the shipped config, a warning of a PMT that is on fails the step, so that the fit is looked at. A PMT whose data or fit fails is not stored and is tried again in the next run of the step; without parameters, LDM gives it a NaN calibration.

Inputs

  • raw tier, category mvc, of the run, per PMT.
  • dataprod_config(l200).pmt(filekey): default merged with the per-detector section (DSP settings, as in process_dsp_phy), and calibration: the default section merged with the per-detector section. It sets energy_types, each with qc, fit (keyword arguments of fit_pmt_spe) and quality (max_chi2_dof, max_μ1_rel_err (uncertainty of μ1 relative to μ1), μ1_range and min_n_1).
  • l200.par.rpars.pmtcal[period, run]: existing results of the run (unless reprocess is set).

Outputs

  • l200.par.rpars.pmtcal[period, run]: per PMT and energy type, fit, the result of fit_pmt_spe (μ1, σ1, τ, n_exp, n_1, r2 with uncertainties, x_min, and gof with converged, pvalue, chi2 and dof, without the covariance matrix and the residuals), and cal.func ("1/μ1 * <energy type> * 1e", NaN for a fit with status warning), with a validity entry at the time of the MVC file.
  • Plots: pmt_spe_fit_<energy type> per PMT (LegendMakie recipe of the fit report).
  • Run report pmts_calibration_cal.

Keywords

  • reprocess: discard the existing results of the run and calibrate all PMTs again. Otherwise PMTs that already have results are skipped.
  • timeout: seconds allowed per PMT in parallel (0 = no limit).

Returns

nothing.
